First release. Skills are installable as a Claude Code plugin (`claude plugin marketplace add katjes733/clever-skills`), with the `skills` CLI (`npx skills@latest add katjes733/clever-skills`), or from a clone with `make install`. The `election-voter-guide` skill ships alone: its tests, docs and examples moved to `dev/election-voter-guide/`.
